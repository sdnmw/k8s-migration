# v0.5.0 更新日志

本版本主要新增平台内离线使用文档和 Nextcloud 图解迁移教程，并修复 Kubernetes 卷传输进度统计问题。以下为相对 v0.4.0 的更新。

## 新增功能

- **平台内使用指引**：登录后可从右上角“使用指引”打开文档，也可直接访问平台同源 `/docs/`，不需要再次登录或连接互联网。
- **离线文档搜索与阅读**：支持本地全文搜索、章节导航、页内目录、代码复制、截图放大和手机浏览；文档随原 Web 镜像交付，不需要额外部署服务。
- **完整平台操作说明**：新增核心概念、功能说明、离线安装、升级、组件运维与常见故障处理，说明按钮用途、填写要求和操作后的预期结果。
- **两套 Nextcloud 迁移教程**：分别演示 Docker Compose 的数据库/文件卷迁移，以及 Kubernetes 的资源/PVC 迁移；涵盖应用发现、评估、映射、执行、数据校验、人工切流和恢复源端，配有逐步操作截图。
- **Kubernetes 示例清单**：提供 Nextcloud、MariaDB、Redis 及两个 PVC 的部署示例，便于准备教程源应用。

## 问题修复

- 修复 Velero 在部分卷已上报传输字节、但尚未上报总量时的进度统计问题。现在会保留已传输数据，并使总量至少包含这些已知字节，避免多卷进度出现“已传输量大于总量”的无效记录；同时覆盖恢复阶段的数据传输统计。

## 升级说明

- 使用本 Release 的 `linux/amd64` 离线包及配套 `.sha256` 文件，按 [离线部署指南](https://github.com/sdnmw/k8s-migration/blob/main/README.md#第一部分离线部署指南) 安装或升级。
- 已有数据库、凭证、管理员密码与对象存储配置保留，不需要删除环境或重建平台。
- 升级后若旧浏览器标签没有显示“使用指引”，强制刷新页面后再打开。
- 升级不会自动迁移业务或切换 DNS/VIP；迁移和切流仍由用户按任务流程执行。

构建依赖的已知安全告警及本次测试记录见 [验证与构建记录](https://github.com/sdnmw/k8s-migration/blob/main/docs/releases/v0.5.0-validation.md)。
