# v0.5.0 验证与构建记录

本文保留本次发布的实验室验证、构建边界和安全事项，供维护者追溯。面向使用者的功能变更见 [v0.5.0 更新日志](./v0.5.0.md)。

## 交付内容

- Docusaurus 3.8.1 简体中文文档站：8 个章节分组，27 个静态页面，50 张真实 1440×900 操作截图。
- 核心概念、关键特性、两个 Nextcloud 教程、全部导航及功能操作、离线安装、升级、运维和故障排查。
- 本地搜索、目录、上一页/下一页、代码复制、图片放大、数字标注、局部放大和移动端适配。
- 平台右上角“使用指引”在新标签页打开同源 `/docs/`；无需再次登录，无外部字体、CDN 或平台 API 依赖。
- 文档及 Kubernetes 示例清单编入现有 Web 镜像，不增加 Service、端口或镜像。
- 修复 Velero 进度中部分卷尚未报告总量时的字节统计约束问题，补充回归测试。
- 提供 Netlify 构建配置；本次没有发布公网文档站。

## 测试与离线边界

- Go test/vet；前端 lint、18 项测试和生产构建通过。
- 文档 npm ci、类型检查、根路径/离线路径生产构建及断链检查通过。
- 静态检查覆盖截图尺寸、图片、内部链接和本地搜索索引。
- 浏览器阻断所有非同源请求后，搜索、深链接刷新、图片放大可用；390×844 无横向溢出；无需平台 API。
- 完整离线包包含 16 个 linux/amd64 镜像；归档 Manifest、OCI 描述树、平台架构和 SHA-256 校验通过。不会覆盖 v0.4.0。

基础镜像源超时时，发行镜像使用本机已有运行层组装全新编译的 v0.5.0 二进制和静态文件；部署采用离线包中锁定的摘要。

## 已知安全事项

指定的 Docusaurus 3.8.1 构建依赖有 npm audit 已知告警，不宣称安全扫描通过。Web 运行镜像不包含 Node/Docusaurus 开发服务，只提供静态页面；可信维护者构建，后续依赖更新需重新验收。安装默认密码仅用于新安装，升级保留已有账号密码。密码、Token、Secret 值、kubeconfig 和私钥不进入截图或教程。

安装入口及 Release 校验文件：GitHub `v0.5.0`，`sks-migration-center-0.5.0-linux-amd64.tar.gz` 与同名 `.sha256`。解压后不要改写已登记交付文件。
