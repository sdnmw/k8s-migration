# SKS Migration Center v0.1.0

首个可部署版本，面向一次性 Kubernetes 与 Docker Compose 应用迁移到 SmartX SKS 工作负载集群的场景。

## 交付物

- Git 仓库：完整 Go/React 源码、测试、Helm Chart、离线安装器源码与运维文档。
- `sks-migration-center-0.1.0-linux-amd64.tar.gz`：包含 16 个 `linux/amd64` OCI 镜像、Chart、静态安装器和部署说明。
- `sks-migration-center-0.1.0-linux-amd64.tar.gz.sha256`：归档校验值。

归档大小为 609 MiB，SHA-256 为 `faa9fe0a22c457a9528a418899c9f9418a08be5a31bf7ad34d2385953224b5cb`。

## 主要能力

- Kubernetes Namespace 自动发现或按 Namespace 手选资源迁移。
- Docker Compose 应用自动发现和手动注册，支持 named volume 与允许目录内的 bind mount。
- 预同步、最终停机同步、目标恢复、完整资源验证、人工切流和源端恢复。
- StorageClass、Namespace、Registry/Image、IngressClass、NodeLabel 与 NFS 资源映射。
- 迁移源端、转换和目标端的资源拓扑，以及逐资源状态、映射证据和执行时序。
- 自包含 HTML 迁移诊断报告，可离线查看。
- 默认单实例 MinIO、额外 MinIO 或外部 S3 三种对象存储接入方式。

## 部署

下载归档和 SHA-256 文件后先校验：

```bash
shasum -a 256 -c sks-migration-center-0.1.0-linux-amd64.tar.gz.sha256
tar -xzf sks-migration-center-0.1.0-linux-amd64.tar.gz
```

准备 Harbor 用户名和密码文件、目标 SKS 工作负载集群 kubeconfig，然后执行：

```bash
./deploy.sh \
  --harbor-address https://harbor.example.com \
  --harbor-project sks-migration \
  --harbor-username-file /secure/harbor-username \
  --harbor-password-file /secure/harbor-password \
  --sks-kubeconfig /secure/target-sks.yaml
```

全部参数和升级说明见 [`deploy/offline/README.md`](../../deploy/offline/README.md)。
