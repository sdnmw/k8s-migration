# SKS Migration Center v0.2.0

v0.2.0 是完整 AMD64 离线发行版，包含平台 API、Worker、Web、PostgreSQL、MinIO、Velero、Kopia、Kompose、NFS CSI 及迁移辅助镜像。

2026-09-21 重建资产对应源码提交 `a56feac`，包含最新迁移修复、离线部署修复和实迁使用手册。

## 本次修复

- 迁移计划的目标映射改为可选。未配置映射时，Compose 自动按项目名创建目标 Namespace；Kubernetes 保持源 Namespace 和未命中的资源值，并使用目标集群可用默认值。
- 映射规则按命中生效，不再为了创建迁移计划要求存在空映射配置。
- 业务迁移 Namespace 不再由平台强制设置 `restricted` 或 `baseline` Pod Security Admission 标签。
- 升级后再次处理由平台管理的既有迁移 Namespace 时，会移除旧版平台写入的 Pod Security enforce 标签；用户自行管理的安全策略不会被覆盖。
- 包含 v0.1.0 之后的 Compose 发现、镜像自动收口、迁移证据拓扑、HTML 报告、失败重试与源端恢复等修复。
