# SKS Migration Center v0.3.0

v0.3.0 是完整 AMD64 离线发行版，包含平台 API、Worker、Web、PostgreSQL、MinIO、Velero、Kopia、Kompose、NFS CSI 及迁移辅助镜像。

## 本次变更

- 存储配置的操作名称改为“准备存储并验证”和“重新验证读写”，明确区分 NFS CSI/StorageClass 准备与单独读写复测。
- 修正 Kubernetes StorageClass 映射后的目标拓扑验证，不再用源端 StorageClass 名称检查目标集群。
- 包含 v0.2.0 以来的 Compose 发现、镜像自动收口、迁移证据拓扑、HTML 报告、失败重试、源端恢复、可选目标映射及业务 Namespace 安全策略修复。
