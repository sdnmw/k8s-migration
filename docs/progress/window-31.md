# Window 31 — 发现、任务操作与拓扑交互修复

日期：2026-09-10

## 已实现

- SSH 主机指纹不再必填：首次读取并固定主机密钥，后续连接仍校验主机是否变化。
- SSH stdout/stderr 分离：Compose 的弃用警告不再污染 JSON/YAML。
- Compose 主机发现执行完整 `docker compose config`，在源主机解析 `.env` / `env_file`。完整定义加密保存，Inventory 不回显环境变量值。
- 若源用户无法读取项目文件，只对固定的只读配置命令尝试现有 `sudo -n` 权限；不提示/传输 sudo 密码、不修改文件权限、不启动或停止服务。
- 发现失败不再被吞掉并显示“成功发现 0 个应用”。上传不完整 Compose 文件时明确提示使用主机发现；真实空项目列表单独提示。
- 手选 K8s 资源仅提交 apiVersion/kind/namespace/name，不再把 Inventory 附加字段提交给严格解码器；请求容量增加到 2 MiB。
- 无 PVC 的 K8s 迁移不再停止源业务；取消/回滚不再要求不存在的副本快照。有卷的副本等待增加三分钟超时，并将超时上下文传入 API 查询。
- Worker 在线不再直接等同“迁移执行正常”；持续三分钟没有关键事件时提示长时间无进展。
- 终态任务支持“编辑后重新执行”：读取原计划，保留策略与验证配置，重新评估后创建新任务。
- 支持终态任务删除（软归档）：从列表移除，不删除业务资源、备份和恢复证据；活动任务拒绝删除。
- 拓扑重复证据提示去重；节点、关系和映射详情使用右侧抽屉，移除右下角 MiniMap。
