# ADR 0002：工具链与离线交付基线

- 状态：已接受
- 日期：2026-09-02

## 决策

- Go 工具链固定为 1.26.5，默认在容器内运行。
- 前端构建工具链固定为 Node.js 24.20.0；开发时最低兼容 Node.js 22。
- 本地环境使用 Docker Compose，生产环境使用 Helm Chart。
- 生产镜像使用非 root 运行时；依赖镜像最终必须进入离线镜像锁文件并固定 digest。
- 离线发行包必须包含镜像、Chart、CRD、SBOM、签名和校验清单。

## 说明

窗口 1 只锁定开发工具链和容器入口。具体的 Kubernetes、Velero、MinIO、NFS CSI 镜像 digest 在离线交付窗口通过真实目标集群兼容性测试后固化。
