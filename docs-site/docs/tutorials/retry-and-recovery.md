# 失败定位、编辑、重试与恢复

1. 打开失败任务，先阅读页面顶部的直接原因。
2. 在 **执行时序** 展开失败 Step 和 Attempt，检查最后心跳、事件和错误详情。
3. 在 **资源拓扑** 点击红色节点，查看执行时结论、当前状态、事件、转换差异和关联资源。
4. 在 **数据迁移** 查看具体 PVC/volume 的引擎、快照和传输错误。
5. 从右上角 **…** 选择 **编辑任务**，修改映射、存储、验证或切流参数。
6. 在预填向导重新评估、保存并检查，在确认页启动新 Run；若完全不改配置，可直接从原任务选择 **重新执行**。历史 Run 不会被覆盖。

如果源端已停止且不准备继续割接，选择 **恢复源端**。恢复操作按执行前快照恢复 Compose 服务状态或 Kubernetes 副本数；目标端资源不会自动删除。

只有不再需要在列表中保留记录时才删除任务。删除前先下载完整 HTML 报告；删除任务仅移除列表记录，不删除源/目标业务、备份或证据。备份清理是独立操作，应在回滚窗口结束后执行。
