# 概览与导航

概览页用于判断平台是否适合立即创建迁移，而不是代替具体任务诊断。重点查看环境连接、运行中/需要处理任务、目标集群与存储组件健康。

右上角 **使用指引** 在新标签页打开同源离线文档 `/docs/`；管理员菜单提供修改密码和退出登录。侧边栏按环境、迁移策略和系统设置分组，展开状态不会影响当前任务。

出现告警时优先进入对应环境或任务查看直接原因。概览上的聚合数字不会覆盖任务详情里的证据。
