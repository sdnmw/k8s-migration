# 管理员密码与退出

点击右上角管理员名称打开菜单。

## 修改密码

1. 点击 **修改密码**。
2. 输入当前密码、新密码和确认密码。
3. 新密码至少 12 个字符，且不能与当前密码相同。
4. 成功后全部现有会话退出，使用新密码重新登录。

平台不会显示当前密码。忘记密码时联系有平台及数据库管理权限的运维人员恢复账号；当前界面没有“忘记密码”或邮件重置入口。修改应用 Secret 后重启并不会重置数据库中已有管理员密码，不要直接编辑密码散列。

## 退出登录

点击 **退出登录** 会清理当前会话并返回登录页，不影响正在运行的迁移任务。
