# 迁移任务与详情

## 任务列表

可按全部、进行中、成功、失败、需要处理筛选，并按任务名或源环境搜索。列表显示类型、源环境、目标、应用/Namespace、状态、流程进度和数据量。

每行 **…** 菜单包含适用操作：查看、编辑任务、重新执行、恢复源端和删除任务。运行中的任务不会提供会破坏状态的操作。

## 创建迁移六步向导

| 步骤 | 必填输入 | 结果 |
| --- | --- | --- |
| 源环境 | 已连接环境 | 读取应用或 Namespace |
| 选择应用 | 自动发现应用或手选资源 | 固化 Inventory |
| 迁移评估 | 目标 SKS | 得分、BLOCKER、WARNING |
| 目标映射 | 计划名称；可选资源映射、卷策略、预同步、HTTP 检查 | 保存计划并发起前置检查 |
| 迁移检查 | 阅读 PASSED/WARNING/BLOCKER 及修复建议 | 检查通过后才可下一步 |
| 确认 | 核对摘要并勾选人工切流声明 | 点击“确认并启动”创建 Run |

第一次点击“执行评估”只生成评分，不自动进入下一步；评分出现后再点“下一步”。第四步“保存并执行检查”已经写入计划，最后一步才启动任务。离开未启动的确认页不会停止一个尚未创建的 Run。

卷策略：Compose 固定使用 Kopia 文件级迁移；Kubernetes 可选 FSB、CSI Data Mover 或 NONE。NONE 不复制 PVC 内容，不能用于带数据库的 Nextcloud。HTTP 检查每行一个目标 URL，必须从 Worker 所在网络可达；不填不等于实际业务功能已经验收。

## 详情页四个页签

- **资源拓扑**：源端、转换、目标端关系；节点和连线可聚焦。
- **执行时序**：Step、Attempt、心跳、租约、事件和等待原因。
- **数据迁移**：每个 PVC/volume 的引擎、快照、字节数、校验和错误。
- **任务信息**：计划、环境、映射、策略、时间、切流与源端恢复状态。

顶部下载按钮生成完整离线 HTML 报告。任务顶部状态结论和资源统计是最终判断依据；流程进度只表示步骤完成比例。

## 拓扑的每个控件

搜索输入框按名称缩小资源范围；类型下拉按 Kind 筛选；辅助资源开关显示 ConfigMap、Secret、RBAC 等。应用视图按业务链路对齐源/转换/目标，资源视图按实际资源依赖排列。左下加减按钮缩放，Fit View 自动适配全部可见节点，拖动画布改变视口。

点击节点或迁移映射线，只聚焦相关节点与连线，其他资源置灰；点击空白处取消聚焦。下方详情分“资源属性”“转换差异”“关联资源”：属性展示镜像、端口、挂载和验证；差异显示字段的源值/目标值与规则；关联资源显示方向、关系类型和可点击的资源名。Secret 只展示键名，不能用详情页读密码。

“刷新当前状态”查询目标现状，不改写终态任务快照；检查时间和漂移数说明当前观察是否新鲜。红节点需查看详情直接原因及执行时序，再查对应 Pod events，而不是只看 Pod 现在 Running。

## 高风险按钮的边界

| 操作 | 会做什么 | 不会做什么 |
| --- | --- | --- |
| 确认切流 | 确认管理员已完成外部入口切换，完成任务 | 不改 DNS/LB/防火墙 |
| 恢复源端 | 重新启动原 Compose 服务或恢复原副本数 | 不把外部流量自动切回；不删除目标 |
| 重新执行 | 原计划创建新 Run，保留旧证据 | 不覆盖旧任务历史 |
| 编辑任务 | 用原配置预填向导，允许调整后创建新计划 | 不就地改写旧 Run |
| 删除任务 | 从列表移除任务记录 | 不删除业务资源或备份文件 |
| 清理备份 | 清理该 Run 的迁移备份/恢复对象 | 不作为删除业务的入口 |

恢复源端后两端都能写入时会产生分叉；教学演示允许分别验证，生产环境必须明确唯一写入端。清理备份前确认回滚窗口已结束。
