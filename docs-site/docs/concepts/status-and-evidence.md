# 状态、验证与证据

## 三个容易混淆的指标

- **流程进度**：步骤完成比例，失败任务也可能是 100%。
- **资源验证结果**：目标资源是否创建、健康、映射生效以及当前是否漂移。
- **任务结论**：综合步骤、必要资源、数据验证和切流状态得出的成功、成功有告警、失败或需要处理。

## 资源颜色

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 已创建并验证健康 |
| 蓝色 | 已创建，等待验证或映射证据 |
| 黄色 | 迁移成功但存在非阻断告警 |
| 红色 | 创建、映射或验证失败；详情区必须显示直接原因 |
| 灰色 | 未迁移、辅助资源，或当前聚焦关系之外的资源 |

## 拓扑交互

点击节点或连线会高亮完整关联路径，其他资源变灰。下方详情区展示资源属性、执行时结论、当前观察、转换差异、关联资源和相关事件。源端、转换和目标端按业务层级自上而下排列，避免把同名但无依赖关系的资源强行串联。

## HTML 报告

报告保存任务摘要、拓扑、步骤、数据传输、验证和事件，使用内嵌样式与资源，可离线打开。密码、Token、Secret 值、kubeconfig 和私钥不会进入报告。
